## 查找资料

课程目录按资料用途分类，具体以各课程实际收录为准：

| 目录 | 内容 |
| --- | --- |
| 教材 | 教材、配套习题与参考资料 |
| 课件与个人总结 | 课堂课件、学习笔记与个人总结 |
| 期中 / 期末 | 相应阶段的复习资料、试卷与参考答案 |
| 考试资料（期次待核） / 其他待确认 | 尚未确认考试期次或资料归属的文件 |

文件名中的“模拟”“回忆”“手写作答”“归属待核”等标注用于区分资料性质；入学年级与考试学年也分别保留。查找试卷时，可结合课程、年份和这些标注筛选。

## 关于归档

本仓库来自个人学习过程中的资料整理，包含教材、教师课件、第三方试题与个人笔记。各课程的收录范围不同，学期划分仅用于归档导航。

资料保留原有来源与性质说明，收录不代表本人原创。复习时请结合当学期的教学内容与课程要求使用。
