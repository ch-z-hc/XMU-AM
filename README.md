## 关于资料

文件名保留“模拟”“回忆”“手写作答”“归属待核”等说明，也区分入学年级与考试学年，查找时可以据此辨别资料性质。

资料来自个人学习归档，包含教师课件、教材、第三方试题和个人笔记；收录不代表本人原创。
