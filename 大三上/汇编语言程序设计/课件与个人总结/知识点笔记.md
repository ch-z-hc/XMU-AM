# SAMPLE 程序学习笔记

先记住这个程序的任务：比较两段文字，根据比较结果选择一条提示。理解下面这几条指令，就能看懂它的主体。

```asm
lea si,string1
lea di,string2
cld
mov cx,25
repz cmpsb
jz match
```

## 1. 源文件怎样变成程序

```text
SAMPLE.ASM --MASM 汇编--> SAMPLE.OBJ --LINK 链接--> SAMPLE.EXE
```

ASM 是写给人看的汇编源代码。MASM 把指令翻译成机器码，生成 OBJ。LINK 处理段之间的地址关系等信息，生成 DOS 能装入的 EXE。修改 ASM 后，要重新汇编、链接，EXE 才会随之改变。

DOSBox 提供 DOS 运行环境，DEBUG 用来查看和控制程序执行。它们在这个实验中承担不同的工作。

## 2. 寄存器在程序里负责什么

寄存器是 CPU 内部用来保存数据和地址的小存储单元。这个程序重点看下面几组：

| 寄存器 | 本实验中的用途 |
|---|---|
| DS、ES | 两个字符串所在的数据段 |
| SI、DI | 两个字符串当前比较位置的偏移地址 |
| CX | 还可以比较多少个字节 |
| CS、IP | 下一条程序指令的位置 |
| AH | 选择 DOS 服务功能，本程序设为 09h |
| DX | 要显示的提示文字的偏移地址 |

ZF 是标志位，记录某些运算结果是否为零。在字节比较后，可以通过它判断两个字节是否相等。

### 为什么地址写成 DS:SI

8086 用「段地址:偏移地址」定位内存。例如 DS:SI 中，DS 提供段地址，SI 提供段内偏移。

物理地址的计算是：

```text
段地址 × 16 + 偏移地址
```

因此程序既要设置 DS、ES，也要设置 SI、DI。只设置偏移地址，还不能确定字符串在内存中的位置。

`ASSUME` 是给汇编器看的段对应说明，不会在运行时替你设置寄存器。真正设置数据段的是：

```asm
mov ax,datarea
mov ds,ax
mov es,ax
```

## 3. LEA 和 DB

```asm
string1 db 'Move the cursor backward.'
lea si,string1
```

DB 表示按字节定义数据，这一行将字符串的字符代码依次放入数据段。LEA 将 string1 的偏移地址送入 SI，SI 得到的是字符串的位置，而不是某个字符的代码。

ASCII 中，大写 M 的代码是 4Dh，小写 m 是 6Dh，空格是 20h。DEBUG 的 D 命令会同时显示字节的十六进制值和可显示字符，所以能从数据区看见文字。

## 4. CLD、CMPSB 和 REPZ

CLD 把方向标志 DF 清为 0。这样，字符串操作执行后，SI、DI 向高地址移动。

CMPSB 比较 DS:SI 和 ES:DI 指向的两个字节。它按减法结果设置标志，但不把减法结果写回字符串。若两个字节相同，结果为零，ZF=1；若不同，ZF=0。DF=0 时，SI、DI 各增加 1。

REPZ 让这个比较重复执行，用 CX 控制次数：每次比较后，CX 减 1；如果 CX 已为 0，或者比较后 ZF=0，就不再继续。这里不需要单独写 LOOP 指令。

本程序可理解为：

```text
最多比较 25 个字节；一旦发现不同，就停止比较。
```

### 本次为什么 CX=0008

```text
共同部分：Move the cursor        共 16 个字符，末尾包含空格
下一字符：backward. 的 b，对比 forward. 的 f
```

第 17 个字符不同，所以已经比较 17 次，剩余 25-17=8 次。

```text
CX = 25 - 17 = 8  = 0008h
SI = 0  + 17     = 0011h
DI = 25 + 17     = 002Ah
ZF = 0，DEBUG 显示 NZ
```

如果原来的两串完全相同，就比较完 25 个字节，CX=0000、SI=0019、DI=0032，最后一次比较的 ZF=1，DEBUG 显示 ZR。

本机 DOSBox 执行 T 时，会一次完成这条重复比较指令。不能把一次 T 一定看成「只比较一个字符」；要看暂停后的 IP、CX 和标志。教材显示的逐字符跟踪过程，可以结合这些最终值理解。

## 5. JZ、JNZ 和标志位

| 比较结果 | ZF | DEBUG 显示 | JZ | JNZ |
|---|---|---|---|---|
| 两字节相等 | 1 | ZR | 跳转 | 不跳转 |
| 两字节不同 | 0 | NZ | 不跳转 | 跳转 |

JZ 的意思是「零标志为 1 时跳转」，不是「CX 为 0 时跳转」。本程序的 JZ 检查的是比较留下的 ZF。相同字符串比较完时，CX=0 和 ZF=1 会同时出现，但它们是两件事。

```asm
jz match
lea dx,mess2
jmp short disp
match:
lea dx,mess1
```

ZF=1 时跳到 match，选择 Match.；ZF=0 时顺序执行 LEA DX,mess2，选择 No match!。把 JZ 写成 JNZ，就把这两个条件反了。因此，即使两个字符串相同，也会显示 No match!。

## 6. DOS 怎样显示文字

```asm
lea dx,mess1
mov ah,09
int 21h
```

INT 21h 调用 DOS 服务，AH=09h 选择显示字符串的功能。DOS 从 DS:DX 指向的位置读字符，遇到 `$` 停止。

```asm
mess1 db 'Match.',13,10,'$'
```

这里的 13 是回车，10 是换行，它们都按十进制写出；`$` 是这个 DOS 功能要求的结束标记，不会显示在屏幕上。被比较的 string1、string2 没有 `$`，因为比较次数由 CX 指定。

## 7. 开头的 PUSH 和最后的 RET

本程序的 MAIN 是 FAR 过程，RET 被汇编成远返回指令 RETF。远返回要从栈中取出 IP 和 CS。

程序开始时 DS 指向程序的 PSP 段。先 PUSH DS，再将 AX 清零并 PUSH AX，栈顶就有偏移 0000，下面有 PSP 段地址。最后远返回到 PSP:0000，由该处的 DOS 结束指令退出程序。这是教材采用的一种旧 DOS 程序返回方式。

所以这几条 PUSH 是在准备返回地址。它们并不是建立一个新的 STACK 段；教材没有声明 STACK 段，因此 LINK 会给出相应警告。

## 8. 十进制和十六进制不要混用

```asm
mov cx,25       ; MASM 中无后缀的 25，默认是十进制
mov cx,19h      ; 明确写成十六进制，与上一条的值相同
```

DEBUG 默认把数字按十六进制解释。

```text
DEBUG 中 19 = 十进制 25
DEBUG 中 25 = 十进制 37
DEBUG 中 10 = 十进制 16
```

因此看到 CX=0019，表示剩余 25 次；看到 SI=0011，表示前进了 17 个字节。G19 中的 19 是代码偏移地址，虽然也等于十进制 25，但它在命令中的作用是定位断点。

## 9. 常用 DEBUG 命令

| 命令 | 用途 | 本实验例子 |
|---|---|---|
| R | 查看或修改寄存器 | r、r ip |
| D | 查看内存字节 | d0 |
| U | 反汇编机器指令 | u0 29 |
| E | 修改内存字节 | e29 'forward.' 20 |
| A | 在内存中汇编指令，也支持 DB | a19，然后输入 jz 0021 |
| F | 按给定内容填充一段内存 | f29 l9 'forward.' 20 |
| G | 运行，可以指定断点 | g0b、g19 |
| T | 单步跟踪 | t |
| P | 单步执行，可越过调用、循环等 | p |
| Q | 退出 DEBUG | q |

`g0b` 表示从当前执行位置继续，停在 CS:000B，不表示从 000B 开始运行。`r ip` 修改的是 16 位 IP 寄存器；它也可以连写为 `rip`，不要将这种命令写法与 64 位 CPU 的 RIP 寄存器混淆。

A 命令默认使用代码段地址。修改字符串时要指定数据段，例如 `a076a:29`，其中 076A 要换成当前 DS 的值。程序每次装入的位置可能变化，段地址不能固定照抄。

## 10. 自己做一次小练习

双击「教材第一章实验」快捷方式。在 C:\CH1 下输入：

```text
debug sample.exe
g0b
e0 6d
g19
```

这次将第一个字符串开头的大写 M 改为小写 m，第二个字符串不变。先想一想：程序会比较几次？CX、SI、DI 和 ZF 会是什么值？

运行到断点后，核对以下预期值：

```text
CX=0018，SI=0001，DI=001A，标志 NZ
```

第一对字符就不同，只比较 1 次，因此剩余次数是 24，即 18h；两个偏移地址各加 1，ZF=0。再输入 G，程序会显示 No match!。最后 Q 退出；重新装入 SAMPLE.EXE，原来的大写 M 会恢复，因为刚才改的是内存。

这个练习能检查你是否分清了比较次数、地址变化、标志位以及磁盘文件与内存的区别。
