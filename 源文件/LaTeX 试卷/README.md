# LaTeX 试卷

PDF 与同名源码目录放在一起，课程原目录保留相同的 PDF。本目录有 32 套可编辑的 LaTeX 源码，覆盖力学、热学、UNIX 系统编程、大学物理、离散数学、概率统计、计算方法、计组和计网；另保留 11 份已有的 PDF。试卷仅保留题目，必要的题图、表格随源码提供。

`公共模板/` 保存编译时使用的 exam-zh v0.3.6 类文件、模块和中文字体配置，原许可证见其中的 `LICENSE`。

## 字体

自行准备有权使用的字体，放进本目录下的 `字体/`（不随仓库上传）：

- `STSong.ttf`、`STHeiti.ttf`、`STHeitiMedium.ttc`。最后一个文件须包含 SC Medium 字体，配置使用索引 1。
- New Computer Modern 的 `NewCM10-*.otf`、`NewCMSans10-*.otf`、`NewCMMono10-*.otf` 和 `NewCMMath-Book.otf`，包括 Book、Bold 及相应斜体版本。

不使用宋体、黑体或 Times 替换上述字体。

## 编译

使用 Tectonic。在某一套试卷的源码目录中运行，例如：

```powershell
tectonic -Z search-path="../../../公共模板" -Z search-path="../../../字体" paper.tex
```

各套试卷的主文件统一为 `paper.tex`，避免 Windows 下含空格的主文件名影响辅助文件读取。首次编译可能需要下载 TeX 依赖。

2018—2019 计组先编译两幅矢量题图，再编译主文件：

```powershell
tectonic -Z search-path="../../../公共模板" -Z search-path="../../../字体" instruction.tex
tectonic -Z search-path="../../../公共模板" -Z search-path="../../../字体" cpu.tex
tectonic -Z search-path="../../../公共模板" -Z search-path="../../../字体" paper.tex
```

这套源码由原构造记录恢复，原先误写的“期末”已更正为“期中”；两幅题图直接使用矢量版。其余 5 套计网、计组源码来自对应 PDF 的原构造文件，仅调整共享字体路径。

## Word 原稿整理

26 套试卷从原 Word 文件重排，公式转为 LaTeX，必要的 Word 自绘图从原稿导出的 PDF 中裁取，不附整页扫描原件。另有 5 份复习、语言材料按原结构导出 PDF，放在课程原目录，不收入这里。

- 离散数学的 3 套原稿未注明学校与年份，现命名为“离散期末参考 A 卷”“离散期末参考 B 卷”“离散期末参考卷 03”。混合 Word 文档属性中的“02~03 年度”无法对应各套卷子，不能当作考试年份；[公开题集](https://zstu.wiki/down/qtkz3runalc/-1149029865/1%20%E6%B5%99%E6%B1%9F%E7%90%86%E5%B7%A5%E5%A4%A7%E5%AD%A6%E7%A6%BB%E6%95%A3%E6%95%B0%E5%AD%A6%E8%AF%95%E9%A2%98%E5%86%8C6%E5%A5%97%E8%87%B32020.pdf)也整套收录了同题，但标作别校不同年份的试卷或练习卷，不能据此认定厦大年份。暂保留作参考，不作为已确认的厦大历年真题。
- 力学 4 份文件的原文件名保留，卷头分别按原稿的 2009、2010、2011、2012 级呈现，不把年级当作考试年份。
- “2014 UNIX 期中”的原稿写有“2012”，PDF 不据此认定年份；“2024 大物 B 下 期末 A 卷”的原稿考试时间为 2025 年 01 月，PDF 保留该时间。
- “2013 级 计算方法期中 A 卷”按原卷卷头的年级命名，2013 是入学年级，不是已确认的考试年份；旧文件名中的 2010 不再用于该卷。另一份“2010 计算方法期中题目课件”的原始 PDF 标题明确包含“计算方法_2010期中考试试卷参考答案.ppt”，保留资料原标年份，并注明课件形式；原稿未明确院系归属。两份材料的第 2 题不同，不合并为同一套卷。
- 热学未署年份的合集不擅自定年。2021 年离散期末 A 卷的“版本 2”与保留版内容完全相同，已去重。

## 题目记录与勘误

- 2025 UNIX 期中卷的程序阅读部分原记录为 6 题，每题 10～12 分；现存材料仅有 5 项内容摘要，缺少完整程序和第 6 题。PDF 保留已知内容，不补写缺失题目。
- 2014 UNIX 期中卷移除整理者批注；“清楚”改为“清除”，函数对照采用原批注明确给出的 `exit` 与 `_exit`，程序语句按卷内代码核对为 `exit(127)`。目录遍历题的教材页码记录互相矛盾，卷内仅保留 `dopath` 函数标识。
