# XMU-AM

厦门大学计算机科学与技术专业学习资料归档，收录教材、课程课件、复习笔记、试卷与答案，按学期和课程整理。

## 目录

| 学期 | 课程 |
| --- | --- |
| [大一上](%E5%A4%A7%E4%B8%80%E4%B8%8A/) | 力学、大学英语、大学语文、微积分、线性代数 |
| [大一下](%E5%A4%A7%E4%B8%80%E4%B8%8B/) | 健身健美、大学物理实验、大学英语、微积分、热学 |
| [大二上](%E5%A4%A7%E4%BA%8C%E4%B8%8A/) | C 语言程序设计、大学物理、数据结构、电力电子技术、离散数学、计算机科学与技术导论 |
| [大二下](%E5%A4%A7%E4%BA%8C%E4%B8%8B/) | 数字逻辑、概率统计、模式识别、电路原理、算法设计与分析、计算方法、计算机图形学、面向对象程序设计 |
| [大三上](%E5%A4%A7%E4%B8%89%E4%B8%8A/) | UNIX 系统编程、汇编语言程序设计、计算机组成原理、计算机网络与通信 |

进入学期后按课程查找，每门课程根据已有材料分为“教材”“课件与个人总结”“期中”“期末”等类别。

## 资料说明

- 原始文档格式和内容予以保留。
- 文件名区分考试学年与入学年级；模拟、练习、回忆、手写作答及归属待核等标记保留，便于辨别资料性质。
- 资料来自个人学习归档，包含教师课件、教材、第三方试题和个人笔记；收录不代表本人原创。
